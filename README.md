# Credentia EXP Wallet

Este repositorio contiene el código base generado para la wallet móvil nativa de Credentia en la red Expanse.

## Instrucciones para compilar

Ya que este ZIP contiene únicamente los archivos personalizados, debes generar la estructura base de Flutter en esta misma carpeta:

1. Extrae este ZIP en tu computadora.
2. Abre tu terminal y navega hacia la carpeta extraída:
   `cd ruta/a/credentia_exp_wallet`
3. Ejecuta el comando de creación de Flutter en el directorio actual para generar los archivos nativos de Android/iOS restantes sin borrar nuestro código:
   `flutter create .`
4. Descarga las dependencias:
   `flutter pub get`
5. Ejecuta la aplicación:
   `flutter run`
